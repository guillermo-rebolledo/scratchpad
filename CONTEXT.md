# Thought Capture

This context covers the rapid capture and later review of short personal thoughts.

## Language

**Thought**:
A Markdown entry without a separate title that remains available until the user explicitly deletes it. A Thought belongs to at most one Project.
_Avoid_: Note, memo, kept thought

**Draft**:
The single unfinished capture text and its selected Project, retained until the user saves it as a Thought or deliberately clears it.
_Avoid_: Unsaved thought, temporary note

**Project**:
A uniquely named collection used to group related Thoughts. A Project may contain any number of Thoughts and can be deleted only when empty.
_Avoid_: Folder, category, tag

**Inbox**:
The collection of Thoughts that do not belong to a Project.
_Avoid_: Default project, uncategorized project

**Trash**:
The collection of deleted Thoughts that can still be restored or permanently removed. Trash remembers a Thought's former Project for restoration, but that Project is no longer associated with the Thought.
_Avoid_: Archive, deleted project
