# Issue Tracker

Issues for this repository live in Linear:

- Workspace/team: Memoji Inc (`MEM`)
- Team URL: https://linear.app/memoji-inc/team/MEM/overview
- Integration: bundled Linear app

## Workflow

Use the Linear integration to search, read, create, and update issues.

- Default all issue operations to team `MEM` unless the user explicitly specifies another team.
- Read an existing issue before changing it.
- Create issues with a clear title and Markdown description.
- Preserve fields the user did not ask to change.
- Do not use GitHub Issues or `.scratch/` as alternate issue stores unless this configuration is updated.
- If the Linear integration is unavailable or unauthenticated, stop and ask the user to reconnect it.
