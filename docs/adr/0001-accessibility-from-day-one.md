# Accessibility is a release criterion from day one

Thoughtbox treats accessibility as part of feature completeness from the first implementation, not as a later enhancement. Every capture, browsing, editing, Settings, Project, Trash, search, and export workflow must support keyboard navigation and appropriate VoiceOver semantics, maintain sufficient contrast, and honor Reduce Motion where applicable, because retrofitting these qualities after the interface architecture solidifies is costly and would exclude users from the initial release.
