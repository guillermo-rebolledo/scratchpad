# Thoughtbox 1.0 beta 1

Thoughtbox is a free, unlisted beta for macOS 14 or later. It is a small, keyboard-friendly place to capture Markdown Thoughts, organize them into Projects, search active collections, and recover work from Trash.

## What is included

- A durable Draft and global quick-capture shortcut.
- Inbox, Projects, search, multi-selection, and recoverable Trash.
- Rendered Markdown with a canonical Markdown source editor.
- Portable Markdown export for active Thoughts and explicitly selected trashed Thoughts.
- Signed automatic update checks through **Thoughtbox > Check for Updates…**.

Thoughtbox stores its library locally on this Mac. It has no account, analytics, advertising, sync service, or background upload of Thought content.

## Beta limits

- Images are represented by their alt text; image files are not loaded or exported.
- Import is not available in this beta.
- Sync between Macs is not available in this beta.
- The interface is currently English only.

Before installing a later build, use **Export > Export All…** to make a portable Markdown backup. Thoughtbox requires macOS 14 or later and checks the signed Thoughtbox update channel for new beta builds.
