# Thoughtbox 1.0 beta 5

This update makes it faster to revisit and edit a Thought without opening the main Library, and adds direct row actions for managing Thoughts.

## What is new

- Open a Thought from the menu bar by clicking the Thoughtbox icon or using the configurable Control–Option–T shortcut.
- Choose a specific Thought from All Thoughts, Inbox, or any Project that contains active Thoughts. Your selection is retained until you choose another Thought.
- Edit the complete Markdown source in the menu bar popover and save with Command–Return. Unsaved edits are protected when navigating, and are never redirected if the original Thought becomes unavailable.
- Swipe an active Thought row to move it to Trash. In Trash, swipe to restore a Thought or request permanent deletion with confirmation.

Thoughtbox is a free, unlisted beta for capturing Markdown Thoughts, organizing them into Projects, searching active collections, recovering work from Trash, and exporting portable Markdown.

Thoughtbox stores its library locally on this Mac. It has no account, analytics, advertising, sync service, or background upload of Thought content.

Thoughtbox includes Portable Markdown export and signed automatic updates through **Thoughtbox > Check for Updates…**.

## Beta limits

- Images are represented by their alt text; image files are not loaded or exported.
- Import is not available in this beta.
- Sync between Macs is not available in this beta.
- The interface is currently English only.

Before installing a later build, use **Export > Export All…** to make a portable Markdown backup. **Export All excludes Thoughts in Trash, so restore any trashed Thoughts you need before exporting.** Thoughtbox requires macOS 14 or later and checks the signed Thoughtbox update channel for new beta builds.
